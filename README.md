# ¿Hay ahora fútbol? GNOME extension
A GNOME extension to check if IPs are blocked in Spain due to football broadcasts, using [hayahora.futbol](https://hayahora.futbol).


## Developing
Requires [Bun](https://bun.sh/). If you want to use [NPM](https://npmjs.com)/[PNPM](https://pnpm.io/)/whatever, modify the [`Makefile`](Makefile) yourself.

1. Clone the repo:
   ```
   git clone https://github.com/rajayonin/hay-ahora-futbol-gnome-extension.git
   ```
2. Run:
   ```
   make test
   ```
